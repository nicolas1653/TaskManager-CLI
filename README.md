# TaskManager-CLI
Um gerenciador de tarefas desenvolvido em Python para praticar lógica de programação, estruturas de repetição, listas, condicionais e manipulação de dados.

## 📌 Sobre o projeto

O **TaskManager** é um projeto de linha de comando (CLI) que permite gerenciar tarefas de maneira simples e prática.

O objetivo é facilitar a organização de atividades e consolidar conhecimentos fundamentais da linguagem Python.

## ⚙️ Funcionalidades

Adicionar tarefas
- Remover a última tarefa
- Editar a última tarefa
- Listar todas as tarefas
- Salvar tarefas em um arquivo para manter os dados após fechar o programa

## 🛠️ Tecnologias utilizadas

- **Python 3**
- Terminal / linha de comando
- Estruturas de dados e lógica de programação

## 🚀 Como executar

### 1. Pré-requisitos

Tenha o Python 3 instalado em sua máquina.

Verifique a instalação com:

```bash
python3 --version
```

### 2. Clone o repositório

```bash
git clone https://github.com/nicolas1653/TaskManager-CLI.git
```

### 3. Entre na pasta do projeto

```bash
cd taskmanager
```

### 4. Execute o programa

```bash
python3 main.py
```
